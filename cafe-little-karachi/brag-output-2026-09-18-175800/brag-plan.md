# Brag Plan: Cafe Little Karachi (CLK)

## What is this app?
Cafe Little Karachi is a premium dining and online ordering platform featuring a granular culinary variation engine, interactive Dine-In table selection, and real-time Socket.IO order tracking.

## The angle
Authentic Pakistani culinary craftsmanship meets sleek modern digital ordering: from custom spice levels and portion variations to table QR ordering and live kitchen status updates.

## Hook (first 2-3 seconds)
"Craving authentic Karachi spice?" slams in with deep charcoal luxury styling, followed immediately by the golden emblem "CAFE LITTLE KARACHI" and instant dining mode badges (Dine-In, Takeaway, Delivery).

## Key moments (the middle)
- **Granular Variation Engine**: Selecting Special Chicken Biryani, customizing Portion (Double), Spice Level (Karachi Spicy 🔥), and Add-ons (Shami Kebab) with live price calculation.
- **Dine-In Table Selection**: Interactive table card selection (Table #07 — Indoor Lounge) with zero-friction checkout.
- **Live Order Tracker**: Real-time Socket.IO tracker stepping through Order Placed → Kitchen Prepping → Serving to Table with live pulse indicators.

## Outro / punchline
"The Art of Karachi Flavors. Mastered." Landing on the golden emblem, live order URL, and prominent "Order Now" action.

## User flow worth showing
1. Browse item & configure variations (Portion + Spice + Add-on).
2. Select Dine-In table & place order.
3. Live tracker updates in real-time with WhatsApp order notifications.

## Tone
- Preset: `polished`
- Creative direction: Modern luxury dining platform with dynamic interactive UI demonstrations
- Interpretation: Confident, sleek dark mode with warm saffron gold accents, crisp type hierarchy, and responsive UI micro-interactions.

## Format: landscape — 1920x1080
## Duration: 19.5s
